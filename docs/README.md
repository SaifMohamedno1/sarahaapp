# Sarahapp Documentation

Welcome to the official documentation for Sarahapp, an Express + MongoDB API for sending and receiving anonymous messages with secure authentication and OTP confirmation.

- API Reference: `docs/API`
- Guides: `docs/Guides`
- Models: `docs/Models`
- Utilities: `docs/Utils`
- Middleware: `docs/Middleware`

## Quickstart

- Base URL: `http://localhost:3000`
- Content type: `application/json`

```bash
npm install
npm run dev
```
